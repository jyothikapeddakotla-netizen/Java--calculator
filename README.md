# Java Calculator

A beginner-friendly, console-based calculator written in Java.

## Features
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Prevents division by zero
- Checks numeric input
- Allows repeated calculations until the user exits

## Requirements
- Java Development Kit (JDK) 8 or later

## How to run

1. Open a terminal in the folder containing `Calculator.java`.
2. Compile the program:

   ```bash
   javac Calculator.java
   ```

3. Run it:

   ```bash
   java Calculator
   ```

## Example

```text
===== JAVA CALCULATOR =====

Enter first number: 20
Enter operator (+, -, *, /): +
Enter second number: 10
Result = 30.0

Do you want to calculate again? (yes/no): no
Thank you for using Java Calculator!
```

## Concepts used
- Java class and `main` method
- `Scanner` for user input
- `while` loop
- `switch` statement
- Conditional statements
- Basic arithmetic operators
